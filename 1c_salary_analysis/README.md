# Анализ зарплаты сотрудников (внешняя обработка 1С)

Внешняя обработка для ЗУП 3.1 и БП 3.0 (и других конфигураций на БЗК). Анализирует
начисления, НДФЛ и удержания по всем сотрудникам за последние 3 месяца (период можно
поменять) и выводит отчёт с выводами.

## Что в отчёте

1. **Ключевые выводы**: ФОТ и его изменение, движение численности, средняя и медиана,
   какая статья сильнее всего изменила ФОТ, концентрация ФОТ (доля топ-10 %), доля
   премий, сколько людей с отклонениями и с начислениями ниже МРОТ.
2. **Сводка по месяцам**: ФОТ, численность с начислениями, средняя, медиана, минимум,
   максимум, НДФЛ, удержания, к выплате, изменение последнего месяца к первому.
3. **Структура начислений**: оклад/тариф, доплаты и надбавки, премии, отпускные,
   больничные и пособия, прочее. Для каждой статьи — суммы по месяцам, доля и динамика.
4. **По подразделениям**: ФОТ, доля, численность, средняя на человека в месяц.
   Раздел выводится, если удалось определить подразделение.
5. **Сотрудники, требующие внимания**, с пояснением, что проверить:
   - рост или снижение начислений больше порога (по умолчанию 20 %);
   - нет начислений в начале или конце периода (приём, увольнение, отпуск);
   - пропущенные месяцы;
   - начислено меньше МРОТ (неполная ставка, неполный месяц или нарушение ст. 133 ТК РФ);
   - нестабильные начисления (коэффициент вариации больше 30 %);
   - премии больше 50 % начислений;
   - отрицательные начисления (сторно, перерасчёты);
   - удержания больше 20 % начислений.
6. **Начисления по сотрудникам**: месяцы, итог, среднее, изменение, доля премий, НДФЛ,
   удержания, к выплате, отметки. Отсортировано по сумме начислений.
7. **Виды начислений**: каждый вид расчёта по месяцам, его категория, доля и число сотрудников.

Отчёт формируется в табличном документе, его можно сохранить в Excel или PDF
(Файл → Сохранить как).

## Параметры на форме

| Параметр | По умолчанию |
|---|---|
| С месяца / По месяц | три полных месяца перед текущим (в ноябре 2026: август–октябрь) |
| Организация | пусто — все организации |
| Порог изменения, % | 20 |
| МРОТ | 27 093 руб. (с 01.01.2026); 0 — не проверять |
| Объединять совместительства | нет: каждый сотрудник (основное место и совместительство) отдельно |

Кнопка «Последние 3 месяца» возвращает период по умолчанию.

## Откуда берутся данные

- Начисления, НДФЛ и удержания берутся из регистра накопления
  `НачисленияУдержанияПоСотрудникам` по месяцу регистрации. Тип строки определяется по
  измерению `ГруппаНачисленияУдержанияВыплаты`, выплаты в анализ не входят.
- Подразделение и должность на конец периода берутся из среза последних
  `КадроваяИсторияСотрудников` (ЗУП). Если этого регистра нет, подразделение берётся из
  самого регистра начислений, если там есть такое измерение.
- Перед запросом обработка проверяет состав измерений по метаданным. Поэтому она не
  падает на редакциях, где нет, например, измерения `Подразделение`.
- В запросах указано `РАЗРЕШЕННЫЕ`: пользователь видит только то, что ему разрешено ролями.
- Категория начисления определяется по названию вида расчёта (ключевые слова — функция
  `КатегорияНачисления` в модуле объекта). Если в базе свои названия, допишите туда
  ключевые слова.

## Структура исходников

Исходники лежат в формате выгрузки Конфигуратора («Выгрузить в файлы», формат 2.10,
платформа 8.3.14 и новее):

```
src/
  АнализЗарплатыСотрудников.xml              — описание обработки
  АнализЗарплатыСотрудников/
    Ext/ObjectModule.bsl                     — модуль объекта: запрос, аналитика, вывод
    Forms/Форма.xml                          — описание формы
    Forms/Форма/Ext/Form.xml                 — элементы, реквизиты и команды формы
    Forms/Форма/Ext/Form/Module.bsl          — модуль формы
build.bat                                    — сборка .epf из командной строки
```

## Как собрать .epf

Собирать нужно в **копии рабочей базы** ЗУП или БП, а не в пустой базе: форма
ссылается на тип `СправочникСсылка.Организации`.

**Через Конфигуратор.** Откройте базу и создайте новую внешнюю обработку
(*Файл → Новый → Внешняя обработка*). В окне обработки щёлкните правой кнопкой по
корневому элементу и выберите *«Загрузить из файлов…»* (в некоторых версиях это меню
*«Действия»*). Укажите `src/АнализЗарплатыСотрудников.xml`, затем сохраните результат как
`АнализЗарплатыСотрудников.epf`.

**Из командной строки (надёжнее):**

```bat
build.bat "C:\Program Files\1cv8\8.3.25.1374\bin\1cv8.exe" "D:\Bases\ZUP_copy" Администратор пароль
```

Скрипт вызывает `1cv8 DESIGNER /LoadExternalDataProcessorOrReportFromFiles`. Файл `.epf`
появится рядом со скриптом, протокол сборки — в `build.log`.

## Как запустить

- **Разово:** *Файл → Открыть* → `АнализЗарплатыСотрудников.epf`. Задайте период
  и нажмите «Сформировать».
- **Постоянно:** *Администрирование → Печатные формы, отчёты и обработки →
  Дополнительные отчёты и обработки → Добавить из файла*. Обработка регистрируется
  как дополнительная (функция `СведенияОВнешнейОбработке`, безопасный режим) с командой
  «Анализ зарплаты сотрудников». Назначьте ей раздел, например «Зарплата».

## Если Конфигуратор ругается при загрузке

- *«Неверная версия формата»*: платформа старше 8.3.14. Замените `version="2.10"`
  в трёх XML-файлах на версию из своей выгрузки. Чтобы её узнать, выгрузите в файлы
  любую обработку.
- *Не найден тип `CatalogRef.Организации`*: база не ЗУП и не БП. Удалите реквизит
  «Организация» из `Form.xml` (элемент и реквизит) и из вызова `СформироватьОтчет`
  в модуле формы.
