# Отчёт руководителю в 1С:ERP

Внешний отчёт для **1С:ERP Управление предприятием 2.4 / 2.5** (платформа 8.3.10 и новее).
Показывает в одном табличном документе прямо в 1С то же, что HTML-отчёт из `production/daily_report.py`:

- **Главное**: деньги, кто должен нам, кому должны мы, портфель заказов, выпуск, сырьё; ниже список
  вопросов, требующих решения (кассовый разрыв, просрочка, сорванные отгрузки, нехватка сырья);
- **Деньги**: остатки по банковским счетам и кассам на вчера и сегодня, движение за день и с начала
  месяца, платежи дня с контрагентом, статьёй и назначением, прогноз остатка на 7 дней по срокам оплат;
- **Долги**: дебиторка и кредиторка, просрочка по срокам (до 30, 31–60, 61–90, больше 90 дней),
  должники и кредиторы по убыванию просрочки, поступления и платежи на неделю;
- **Заказы**: новые заказы и отгрузки за день и за месяц, портфель по продуктам с учётом склада
  готовой продукции, просроченные заказы и заказы на неделю с оценкой «есть на складе / успеваем
  выпустить / не успеваем»;
- **Выпуск**: за сутки, с начала месяца, за 7 дней по продуктам, план и прогноз на месяц, полоса по
  дням за 14 суток;
- **Сырьё**: остаток, расход в сутки, на сколько дней хватит с поставкой и без неё, дата поставки,
  статус («нехватка», «заказать», «в норме») и сколько заказать.

Двойной щелчок по строке открывает документ, контрагента или номенклатуру. Отчёт сохраняется в PDF
или Excel и отправляется по почте стандартными командами табличного документа.

## Как собрать файл .erf (10 минут, нужен Конфигуратор)

1. Откройте **Конфигуратор** любой базы (можно пустой) → **Файл → Новый… → Внешний отчет**.
2. Имя: `ОтчетРуководителю`, синоним: `Отчёт руководителю`.
3. **Формы → Добавить** → «Форма отчета» (управляемая), отметьте «Назначить форму основной» → Готово.
   Основную схему компоновки данных создавать **не нужно**.
4. Откройте форму, вкладка **Модуль**: удалите всё и вставьте содержимое
   [`МодульФормы.bsl`](МодульФормы.bsl). Ничего рисовать на форме не нужно: поля, кнопки и табличный
   документ код создаёт сам при открытии.
5. В дереве отчёта: **Действия → Открыть модуль объекта**, вставьте [`МодульОбъекта.bsl`](МодульОбъекта.bsl).
6. **Файл → Сохранить** → `ОтчетРуководителю.erf`.

## Как подключить в ERP

- **Быстро**: в рабочей базе **Файл → Открыть** → `ОтчетРуководителю.erf`. Нужно право на открытие
  внешних отчётов.
- **Для руководителя**: **НСИ и администрирование → Печатные формы, отчеты и обработки →
  Дополнительные отчеты и обработки → Добавить из файла…**. Укажите разделы (например, «Финансовый
  результат и контроллинг») и пользователей. Отчёт появится в списке отчётов раздела.

## Настройки на форме

| Поле | Зачем |
|---|---|
| Дата, Организация | Дата отчёта; пустая организация — по всем |
| Группа сырья | Папка номенклатуры с сырьём. Если пусто, сырьём считается всё, что за 30 дней списывалось в производство |
| План выпуска в сутки | В единицах продукции (т или кг). Нужен для процента выполнения и прогноза месяца |
| Неснижаемый остаток | Ниже этой суммы прогноз денег подсвечивается |
| Прогноз, дней | Горизонт прогноза денег, заказов и закупок (7) |
| Срок поставки сырья, резерв | Для статуса «нехватка / заказать» (7 и 3 дня) |
| Крупный платёж от | Такие платежи дня попадают в «Главное» (3 млн) |

Настройки запоминаются для каждого пользователя. Кнопки «← Вчера» и «Сегодня» сразу перестраивают отчёт.

## Откуда берутся данные

| Раздел | Источник в ERP |
|---|---|
| Деньги | регистры `ДенежныеСредстваБезналичные` и `ДенежныеСредстваНаличные` (ресурс `СуммаРегл`, иначе `Сумма`); перемещения между своими счетами и кассой исключаются |
| Долги и прогноз денег | `РасчетыСКлиентамиПоСрокам`, `РасчетыСПоставщикамиПоСрокам` (срок — `ДатаПлановогоПогашения`); если их нет — `РасчетыСКлиентами` / `РасчетыСПоставщиками` без сроков |
| Заказы | регистр `ЗаказыКлиентов` (остаток к отгрузке), документы `ЗаказКлиента` (срок — `ДатаОтгрузки`), `РеализацияТоваровУслуг` |
| Выпуск | приход в `ТоварыНаСкладах` документами `ЭтапПроизводства2_2`, `ВыпускПродукции`, `ПроизводствоБезЗаказа` |
| Сырьё | остатки `ТоварыНаСкладах`, расход — списание этими же документами и `ПередачаМатериаловВПроизводство`; в пути — `ЗаказыПоставщикам` (дата — `ДатаПоступления`) |

Имена полей отчёт берёт из метаданных: из нескольких вариантов выбирает тот, который есть в вашем
релизе. Если раздел всё же не собрался, отчёт покажет в этом разделе текст ошибки, а остальное
сформирует. Запрос раздела лежит в функции `Получить<Раздел>()` модуля формы, его правит
программист 1С.

## Чем отличается от HTML-версии

- Брак и посменный план из ERP не берутся: в типовой ERP они ведутся по-разному. План задаётся одним
  числом в настройках.
- Цена фенола с биржи не показывается: её собирает отдельный скрипт `spimex_phenol`.
- Потребность сырья на портфель заказов не считается: для неё нужны ресурсные спецификации. Это
  войдёт в отчёт о плановой и фактической себестоимости.

## Что проверено

Синтаксис модулей и все варианты запросов проверены парсером BSL из проекта
[1c-syntax](https://github.com/1c-syntax/bsl-parser), на котором работает BSL Language Server.
На живой базе ERP отчёт не запускался: после первого запуска пришлите текст ошибок из разделов,
если они появятся.
