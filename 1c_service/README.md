# Сервис учёта — внешняя обработка для 1С:ERP 2.5

Две закладки. Ставится и обновляется вместе с остальными обработками ярлыком «Обновить обработки 1С»
(см. `1c_tools/README.md`); открывается ярлыком «Сервис учёта» на рабочем столе.

## Аудит ручной работы (полный аудит)

Ничего не меняет в базе. Укажите период (по умолчанию 3 месяца), нажмите **«Собрать аудит»** (3–15 минут:
просматриваются все документы и справочники), затем **«Сохранить в файл»** и пришлите файл в чат.
Запускать лучше под пользователем с полными правами — иначе разделы 12–14 не соберутся.

**В начале файла — «ЧТО ИЗМЕНИТЬ В 1С»:** список найденных проблем по важности (СРОЧНО / ВАЖНО / ЖЕЛАТЕЛЬНО),
у каждой — где в 1С это исправить. Ниже — подробности по разделам:

| № | Раздел | Что проверяется |
|---|---|---|
| 1 | Сколько документов вводится | все виды за период: всего, в день, строк в среднем, по месяцам, кто вводит |
| 2 | Что именно вводится | частые сочетания шапки, частая номенклатура, одинаковые наборы строк (кандидаты в шаблоны), ежемесячные платежи |
| 3 | Дни без суточных рапортов | будни за 30 дней без «Производства без заказа» |
| 4 | Старые незакрытые заказы | сколько по каждому виду |
| 5 | Чистота документов | непроведённые старше недели, помеченные на удаление, с датой в будущем — по видам |
| 6 | Справочники | самые большие и сколько в них помечено на удаление |
| 7 | Номенклатура | вне папок, без вида и единицы, вероятные дубли по названию, товары без движений 2 года |
| 8 | Контрагенты | без ИНН, дубли по ИНН и КПП |
| 9 | Склад и цены | отрицательные остатки, строки продаж и закупок с нулевой ценой |
| 10 | Связи документов | реализации без заказа, поступления без заказа, рапорты без спецификации, материалы без статьи калькуляции, платежи без статьи ДДС, потребление без статьи расходов |
| 11 | Закрытие месяца | документы закрытия по месяцам за год, себестоимость продаж за 3 месяца |
| 12 | Пользователи и права | сколько с полными правами, кто входит без пароля (только количество) |
| 13 | Регламентные задания | включённые и завершившиеся с ошибкой |
| 14 | Настройки и доработки | включённые функции ERP, доработки по префиксам (`опти_`, `СГ_`…), расширения, доп. обработки, версия ERP |

**Наименований в файле нет.** Контрагенты, номенклатура, пользователи, склады, подразделения, статьи и договоры
заменяются кодами: «Контрагент-3», «Номенклатура-12», «Пользователь-1». Один и тот же объект в пределах файла
всегда получает один код, поэтому повторы видны. Остаются: названия видов документов и значения перечислений
ERP (хоз. операции, статусы) — это стандартные названия программы, а также суммы, количества и даты.
Имя пользователя 1С в файл тоже не пишется.

Галочка **«Показать настоящие наименования»** показывает их на экране, для себя. Файл с ней пересылать не нужно:
в его начале будет предупреждение. Для отправки снимите галочку и соберите аудит заново.

## Старые заказы

**«Найти старые заказы»** показывает незакрытые проведённые заказы всех видов, у которых есть статус «Закрыт»
(заказы клиентов, поставщикам, материалов в производство, на производство и т.д.), если заказ старше указанного
срока (по умолчанию 180 дней) и по нему за этот срок не было отгрузок (для заказов клиентов), поступлений
(для заказов поставщикам) или передачи в производство (для заказов материалов). Двойной щелчок открывает заказ.

**«Закрыть отмеченные»** для каждого отмеченного заказа:
1. ставит статус «Закрыт» и проводит заказ;
2. если ERP не даёт закрыть из-за неотгруженных строк, отмечает их «Отменено» с первой причиной отмены
   из справочника (если справочник пуст, создаётся причина «Неактуальный заказ») и проводит ещё раз.

Отгрузки, поступления и оплаты не меняются. Результат — в колонке «Результат». Вернуть заказ: открыть его
и поменять статус (и снять «Отменено» со строк). В первый раз проверьте на 1–2 заказах.

## Для специалиста 1С

Код — в `src/СервисУчета/Forms/Форма/Ext/Form/Module.bsl`; реквизиты и элементы формы создаются в
`ПриСозданииНаСервере`. Виды заказов определяются по метаданным: документы `Заказ*` с реквизитом `Статус`,
тип которого — перечисление со значением `Закрыт`.
