# Накладная по фото → поступление в 1С:ERP

Вы фотографируете бумажную накладную, а программа сама заполняет документ «Поступление» в 1С.

---

## Три способа — все доступны из одной программы

Вверху окна программы есть строка **«Другие способы»** с двумя ссылками.

| Способ | Когда подходит | Что нужно |
|---|---|---|
| **Фото → Claude** (кнопка «1. Выбрать фото накладной») | Любая бумажная накладная | Ключ Claude API |
| **Встроенное распознавание 1С** (ссылка) | Бумажная накладная, если Claude недоступен | Подписка 1С:ИТС, подключённая Интернет-поддержка |
| **Входящие накладные по ЭДО** (ссылка) | Поставщик присылает накладные в электронном виде: распознавать не нужно, ошибок нет | Электронная подпись организации, подключённое ЭДО |

Если встроенный сервис ещё не подключён, после нажатия на ссылку программа покажет пошаговую инструкцию, как его подключить.

**Совет:** попросите постоянных поставщиков присылать накладные через ЭДО. Тогда фотографировать придётся только накладные от редких поставщиков.

---

## Подготовка — один раз

**1. Скачайте папку на компьютер, где установлена 1С.**

**2. Дважды щёлкните файл `СОБРАТЬ.bat`.**
Подождите около минуты. Рядом появится файл **`Nakladnaya_po_foto.epf`** — это и есть программа.

**3. (Только для способа «Фото → Claude») Получите ключ Claude API.** Это пароль, по которому программа обращается к сервису распознавания.
Ключ создаётся на сайте console.anthropic.com в разделе «API Keys». Создать его может ваш руководитель или ИТ-специалист.
Ключ запрашивается один раз: при первом распознавании программа сама попросит его вставить.

---

## Каждый день

1. В 1С:ERP выберите **Файл → Открыть** и откройте `Nakladnaya_po_foto.epf`.
2. Нажмите **«1. Выбрать фото накладной»** и выберите фото (можно сразу несколько страниц).
   Подождите до минуты: программа сама прочитает накладную и заполнит таблицу.
3. Посмотрите на строки, **выделенные розовым**: для них программа не нашла товар в 1С.
   Выберите товар вручную в колонке «Номенклатура». В следующий раз программа это вспомнит.
4. Нажмите **«2. Создать поступление»**. Откроется готовый документ: проверьте его и проведите.

---

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| «Контрагент с ИНН … не найден» | Этого поставщика ещё нет в 1С. Создайте его как обычно или выберите в поле «Контрагент». |
| «Фото слишком большое» | Перешлите фото самому себе в мессенджере (он уменьшит размер) или снимите чуть дальше. |
| «Формат файла не поддерживается» | На iPhone: Настройки → Камера → Форматы → «Наиболее совместимый». |
| «Не удалось подключиться» | У сервера 1С нет доступа в интернет. Покажите это сообщение ИТ-специалисту. |
| `СОБРАТЬ.bat` пишет «Build failed» | Передайте ИТ-специалисту файл журнала (его путь показан на экране) и файл `README_для_специалиста.md`. |

Документ не проводится автоматически: программа может ошибиться в цифре на плохом фото, поэтому проверку оставляем человеку.
