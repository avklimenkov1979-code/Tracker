# Обновление обработок 1С одним щелчком

| Файл | Что делает |
|---|---|
| `ОБНОВИТЬ.bat` | Ставит и обновляет все обработки (отчёт руководителю, накладная по фото, сервис учёта) на компьютере с 1С, создаёт ярлыки на рабочем столе |
| `make_zip.py` | Собирает общий архив для почты `Obrabotki_1C_dlya_pochty.zip` (сначала запускает проверку) |
| `check_bsl.py` | Проверяет модули 1С на ошибки, которые раньше всплывали только при открытии формы |

## Как работает `ОБНОВИТЬ.bat`

**Первый запуск** — из распакованного архива, после переименования `ОБНОВИТЬ.txt` → `ОБНОВИТЬ.bat`:
1. Находит установленную 1С 8.3 (самую новую версию).
2. Копирует себя в `%LOCALAPPDATA%\Obrabotki1C` — на локальный диск, а не на сетевой рабочий стол.
3. Показывает базы из списка 1С и запоминает выбранную рабочую базу (`nastroyki.txt` в той же папке).
4. Собирает `.epf` всех обработок: сначала во временной пустой базе; если 1С не даёт лицензию
   (её выдаёт сервер), — через рабочую базу в режиме Конфигуратора. В базе ничего не меняется.
   Удачный способ запоминается, в следующий раз пробуется сразу он.
5. Кладёт `.epf` в `%LOCALAPPDATA%\Obrabotki1C\epf` и создаёт на рабочем столе ярлыки:
   - **«Отчёт руководителю»**, **«Накладная по фото»**, **«Сервис учёта»** — запускают 1С с этой базой и сразу открывают
     обработку (`1cv8c.exe ENTERPRISE /IBConnectionString … /Execute …epf`);
   - **«Обновить обработки 1С»** — этот же скрипт.

**Следующие обновления:** сохранить архив из письма в «Загрузки» и щёлкнуть «Обновить обработки 1С».
Скрипт берёт самый свежий `Obrabotki_1C*.zip` (или старые `Otchet_rukovoditelyu*.zip`, `Nakladnaya_po_foto*.zip`)
из «Загрузок», с рабочего стола или из «Документов»; если не нашёл — открывает окно выбора файла.
Архив можно и перетащить мышью на ярлык. Обработка, у которой исходники не изменились, не пересобирается.
Новая версия самого `ОБНОВИТЬ` из архива ставится вместо старой.

**Если сборка не удалась** — текст ошибки 1С показывается в окне и сохраняется на рабочий стол
в `Ошибка_обновления_1С_<дата>.txt`: этот файл и нужно прислать.

Устройство: в начале файла несколько строк `cmd`, которые запускают PowerShell и передают ему текст
файла ниже метки `#PS-START`. Сразу после PowerShell `cmd` выходит (`& exit /b` на той же строке), поэтому
скрипт может безопасно заменить сам себя новой версией.

## Кнопка «Сообщить об ошибке»

Есть в обеих обработках. Сохраняет текстовый файл `Ошибка_<обработка>_<дата>.txt`, в котором:
- версии обработки, конфигурации, 1С на сервере и на компьютере;
- полный текст ошибок с номером строки модуля: в отчёте — по каждому разделу, который не собрался,
  и падение формирования целиком; в накладной — распознавание, создание поставщика, запись поступления;
- сообщения, которые 1С показала на экране;
- ошибки этого пользователя из журнала регистрации за 2 часа (если хватает прав);
- в отчёте — его настройки; в накладной — шапка, строки, как подобрана номенклатура и ответ распознавания.

Ключи Яндекса и Claude в файл не попадают.

Ошибки компиляции формы (форма не открывается совсем) кнопка поймать не может — тогда 1С сама предлагает
сохранить отчёт об ошибке (`Ошибка_….zip`), его и присылать. Такие ошибки ловит `check_bsl.py` до отправки архива.
