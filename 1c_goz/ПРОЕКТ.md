# Отчёты по ПП 874 в 1С:ERP: идеальная схема и изменения в конфигурации

Цель: справка за месяц (прил. 3) и отчёт о фактических затратах по каждому контракту (прил. 1) формируются **без ручной работы и Excel**, по расписанию. Любая цифра раскрывается до первичного документа (п. 1 Правил), отчёт сходится с бухучётом (п. 5).

## Главный принцип

Отчёт по ПП 874 — это **срез бухучёта по трём осям: контракт × статья × партия**. Если эти три оси заполнены в первичных документах и проходят через закрытие месяца, отчёт строится сам — типовым отчётом ERP или нашей обработкой. Если нет, никакой отчёт их не восстановит. Поэтому 80% работы — настройка и дисциплина учёта, и только 20% — код.

```
первичка (ИГК / направление деятельности, статья) → закрытие месяца (20 → 43 → 90.02, распределение 25/26)
   → регламентированный учёт (Хозрасчетный: контракт, статья, подразделение)
   → справка прил. 3 (месяц) → отчёт прил. 1 (нарастающим итогом, партии)
   → проверки сопоставимости → комплект в папку / головному исполнителю
```

## Контрольные соотношения (проверять автоматически каждый месяц)

1. Σ прямых затрат по всем контрактам и «прочей продукции» = оборот Дт 20 в ОСВ (без 20—20).
2. Σ распределённых ОПР по справке = оборот Дт 25 без обособленных статей; то же для 26 / 90.08.
3. Распределено в справке = списано в учёте Кт 25/26 → Дт 20 по каждому контракту. Иначе нужна пояснительная записка.
4. Себестоимость 1700 по контракту = 1300 + 1400 + 1600; проценты 1500 в 1700 не входят.
5. Доля документов ГОЗ без направления деятельности = 0.
6. Статей ERP без кода ПП 874 = 0.
7. Отчёт за прошлый месяц не изменился после отправки (регистр 1.6).
