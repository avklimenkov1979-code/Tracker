# ГОЗ: затраты по ПП 874 — внешняя обработка для 1С:ERP 2.5

Формирует по данным регламентированного учёта:

- **справку по результатам распределения затрат за месяц** (прил. 3 к Правилам калькулирования, ПП РФ от 13.07.2026 № 874);
- **отчёт о фактических затратах по контракту ГОЗ** (прил. 1) нарастающим итогом, по 17 статьям прил. 2 и по партиям реализации;
- **комплект за месяц** — справку и отчёты по всем контрактам с ИГК одним архивом xlsx. Комплект можно формировать и **автоматически по расписанию**.

Обработка ставится и обновляется вместе с остальными ярлыком «Обновить обработки 1С» (см. `1c_tools/README.md`).
Открывается ярлыком «ГОЗ затраты ПП 874».

## Порядок работы

1. **Закладка «Готовность»** → «Проверить готовность» → «Сохранить в файл» → прислать файл в чат.
   Проверка ничего не меняет в базе и показывает:
   - версию ERP и встроенные отчёты ГОЗ;
   - функциональные опции ГОЗ;
   - субконто на счетах 20, 25, 26, 43, 90 и 91;
   - справочник контрактов и реквизит ИГК;
   - долю документов с заполненным контрактом;
   - закрыт ли месяц;
   - сопоставлены ли статьи.

   В начале файла — список «что сделать».
   **«Выгрузка для анализа (без названий)»** — подробнее для настройки версии 2. В выгрузку входят:
   - обороты по парам счетов за 6 месяцев: куда закрываются 25 и 26, как отражается зарплата;
   - учётная политика: флажки и перечисления;
   - статьи с оборотами на счетах 20, 25, 26 и 90.08;
   - контракты: есть ли ИГК, затраты;
   - заполненность контракта, статей и подразделений в документах, включая зарплатные;
   - структура регистров.

   Наименования контрагентов, контрактов, статей, подразделений и договоров заменены кодами вида «Контракт-1», «Статья калькуляции-5». Остаются коды и названия счетов, имена объектов ERP, значения перечислений, суммы и даты. Галочка «Показать настоящие наименования» нужна только для просмотра на экране: такой файл не пересылать.
2. **Закладка «Статьи и настройки»**:
   - «Заполнить статьи» — обработка покажет все статьи калькуляции и расходов ERP и предложит код ПП 874 по названию (такие строки подсвечены жёлтым).
   - Проверьте коды и отметьте «Обособленно» — затраты, не включаемые в цену по ПП 1465.
   - Отметьте «Привнесённые» — покупное у кооперации.
   - Флажок **«АУР по статье 1600»** означает, что счёт 26 закрывается на 90.08 (сноска 2 к прил. 2, п. 24 ФСБУ 10/2026). Он включён по умолчанию.
   - «Учёт по новым правилам с» — 01.01.2027 (п. 41 Правил).
   - «Сохранить настройки» — **под администратором**: тогда настройки общие, их читает и регламентное задание.
3. **Закладка «Отчёты»**:
   - «Справка за месяц» — по всем контрактам. Внизу справки — сверка с бухучётом: если есть расхождения, нужна пояснительная записка.
   - «Найти контракты» → выбрать контракт → «Отчёт по контракту».
   - «Сохранить в Excel» или «Комплект за месяц (zip)».

## Автоматически по расписанию

1. В ERP: **НСИ и администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки → Добавить из файла**, выбрать `GOZ_zatraty_874.epf` (лежит в `%LOCALAPPDATA%\Obrabotki1C\epf`).
2. У команды «ГОЗ: комплект отчётов за прошлый месяц в папку (по расписанию)» задать расписание — например, 12-го числа каждого месяца в 6:00, после закрытия месяца.
3. На закладке «Статьи и настройки» указать **папку на сервере 1С**, куда класть файлы (например, `\\server\ГОЗ\Отчёты`), и сохранить настройки под администратором.

Каждый месяц в папке будут лежать:
- `Справка_прил3_ГГГГ_ММ.xlsx`;
- `Отчет_прил1_<ИГК>_ГГГГ_ММ.xlsx` по каждому контракту.

Итог выполнения пишется в журнал регистрации (событие «ГОЗ 874»).

## Откуда берутся цифры

| Что | Источник |
|---|---|
| Прямые затраты по статьям | Дт 20 (кроме оборотов 20—20) по субконто «контракт» и «статья». Статья → код ПП 874 по сопоставлению. Если статьи нет — по счёту кредита: 10/41 → 0101, 21 → 0110, 60 → 0105, 69 → 0300, 70 → 0201, 71 → 1000, иначе 1100 |
| Возвратные отходы (0103) | Кт 20 Дт 10 по контракту, вычитаются из 0100 |
| ОПР (0800), ОХР (0900) | Кт 25 и Кт 26 в Дт 20 по контракту |
| Коммерческие (1400), АУР (1600) | Дт 90.07 и 90.08 по контракту. Если на счёте нет субконто контракта — распределение по основной зарплате основных работников помесячно (п. 28) |
| Проценты (1500) | Дт 91.02 по контракту (в себестоимость 1700 не входят, п. 9) |
| Итоги 0100, 0200, 0400, 1300, 1700 | По п. 8 и 9 Правил |
| Партии реализации | Проведённые реализации, где контракт указан в шапке или в строках. Количество — из документа, себестоимость партии — Дт 90.02 документа |
| Справка: база | Статья 0201 по контрактам за месяц. ОПР и ОХР — обороты Дт 25 и 26 без обособленных статей. Строка «Прочая продукция» — всё без ИГК |

## Ограничения версии 1.0

- **Нужно закрытие месяца с отражением документов в регламентированном учёте.** Без него Дт 20 пустой.
- По партиям затраты разносятся пропорционально себестоимости отгрузки (или количеству) по структуре затрат контракта. Точная разбивка по статьям внутри каждой отгрузки — после доработок из `ПРОЕКТ.md`.
- Колонка «исключённые затраты» не заполняется: суммы, не согласованные заказчиком, пока вносятся вручную в xlsx.
- Таблица 2 справки считает коэффициент по организации в целом, без отдельной базы по подразделениям.
- Если у вас ERP 2.5.27.107+ или 2.6.2.72+, **основной отчёт — типовой «Фактические затраты ГОЗ»**. Тогда обработка нужна для проверки готовности, сверки с типовым отчётом и регламентной выгрузки.

## Для специалиста 1С

- Расчёты — в `src/ЗатратыГОЗ874/Ext/ObjectModule.bsl`, форма — в `Forms/Форма/Ext/Form/Module.bsl`. Реквизиты и элементы формы создаются в `ПриСозданииНаСервере`.
- Справочник контракта и виды субконто определяются по типам значений субконто, а не по именам.
- Настройки хранятся в `ХранилищеОбщихНастроек`, ключ `ЗатратыГОЗ874` / `Общие`, общий пользователь `ГОЗ874`.
- Регламентная команда — `ВыполнитьКоманду("КомплектЗаПрошлыйМесяц")`.
