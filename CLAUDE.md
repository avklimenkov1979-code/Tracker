# Правила для обработок 1С

- Обработки 1С (папки с `src/*.xml`: `1c_*`, `production/1c`) собираются не Конфигуратором, а ярлыком
  «Обновить обработки 1С» (`1c_tools/ОБНОВИТЬ.bat`) во временной пустой базе. Поэтому `Form.xml` почти пустой,
  реквизиты, команды и элементы формы создаются в `ПриСозданииНаСервере`, типы конфигурации — только в коде.
- Новая обработка добавляется в `$Products` в `ОБНОВИТЬ.bat`, в `PROJECTS` в `1c_tools/make_zip.py`,
  в `1c_tools/ПОДКЛЮЧИТЬ_НАВСЕГДА.txt`; блок обезличивания — через `1c_tools/insert_obezl.py`.
- Архив для пользователя — только `python3 1c_tools/make_zip.py` (проверка `check_bsl.py` + архив без
  исполняемых файлов: `.bat` уходит как `ОБНОВИТЬ.txt`). Почта не пропускает `.bat`, `.ps1`, `.exe` и т. п.
  даже внутри архива — отдельные `.bat` не отправлять.
- **После каждой сборки архив всегда отправлять письмом на рабочую почту пользователя** через Gmail
  (адрес — получатель прошлых писем «Obrabotki_1C_dlya_pochty» в отправленных), с короткой инструкцией
  по обновлению в тексте письма.
